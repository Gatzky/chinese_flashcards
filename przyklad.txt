# Format: znak // pinyin // tłumaczenie
你 // nǐ // ty
好 // hǎo // dobry
我 // wǒ // ja
是 // shì // być
中 // zhōng // środek / Chiny
国 // guó // kraj
人 // rén // człowiek
学 // xué // uczyć się
水 // shuǐ // woda
爱 // ài // miłość / kochać
马上 // mǎshàng // zaraz, natychmiast // [sentence] 我马上回来。 = Zaraz wrócę. // [characters meaning] 马 (mǎ) = koń; 上 (shàng) = na, powyżej
